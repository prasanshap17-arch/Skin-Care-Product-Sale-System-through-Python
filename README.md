# WeCare - Skin Care Product Sale System 🧴

WeCare is a Python-based application developed to manage the sale and inventory of skin care products. The system allows users to view products, process customer purchases, restock inventory, and generate invoices efficiently.

## Features
- Display available skin care products
- Process customer purchases
- Buy 3 Get 1 Free policy
- Restock inventory
- Generate invoices
- Update product information automatically

## Technologies Used
- Python
- File Handling

## Project Purpose
This project was developed as part of coursework to demonstrate programming concepts and the implementation of a product sales management system.
